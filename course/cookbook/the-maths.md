# The maths behind the exercises

The exercises practise **programming**, not maths. Before you code, write the definition and a tiny example on paper.

| Word | What it means | Tiny example |
| --- | --- | --- |
| Sum | add the numbers | 1 + 2 + 3 + 4 = 10 |
| Factorial | multiply 1 × 2 × … × N | 4! = 1 × 2 × 3 × 4 = 24, and 0! = 1 |
| Power | multiply x by itself N times | 3⁴ = 3 × 3 × 3 × 3 = 81, and x⁰ = 1 |
| Fibonacci | each value is the two before added together | 0, 1, 1, 2, 3, 5, 8 |
| Armstrong number | the sum of its digits, each to the power "number of digits", gives the number back | 153 = 1³ + 5³ + 3³ |
| Prime | a number of 2 or more that only divides by 1 and itself | 7 is prime; 9 is not (9 = 3 × 3) |
| Palindrome | reads the same both ways | 1221, "kayak" |

With `int`, keep factorials up to 12: bigger ones do not fit.
