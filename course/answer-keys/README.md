# Solutions

**Stop!** Did you really try? Did you open the hints? Did you fill a trace table?
A solution read too early teaches less than an exercise solved with 3 hints.

- C# code: one file per exercise in [`internal/solutions/`](../../internal/solutions) (`<ID>_<Name>.cs`), linked at the bottom of each exercise page.
- Paper exercises: their answer key is here (`<ID>-<name>.md`), for example [L01](L01-trace-a-loop.md).
- Your solution can be different and still be correct. Compare the **idea** (which recipe? which boxes?), not the exact words.
- The code only uses what the exercise's theme (and earlier themes) teach (no LINQ, no tricks).

## How to try a solution

Each file has the same shape as your file in `practice/` (for example `A04_Factorial.cs`). To see it work, copy its method into your own file, then `./ex check`.

## For the coach

Every solution runs through the same tests as `./ex check` (see `internal/tools/check-exercises.sh`). Details: [AGENTS.md](../../AGENTS.md#checks).
