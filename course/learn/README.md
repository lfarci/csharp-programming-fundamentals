# How it fits together

This course is for **practice**. The **theory** comes from **Microsoft Learn**, free. For each theme, follow the line from left to right: learn the idea on Microsoft Learn, watch the video, then practise here.

<LearnFlow />

<div class="gh-only">

- **1. [Basics](../themes/basics.md)**: learn [Write your first C# code](https://learn.microsoft.com/en-us/training/modules/csharp-write-first/) (Part 1), watch [Creating Your First C# Program](videos/creating-your-first-c-program.md), then practise [B01](../exercises/B01-hello-you.md), [B02](../exercises/B02-rectangle-calculator.md), [B03](../exercises/B03-seconds-to-hms.md)
- **2. [Loops](../themes/loops.md)**: learn [Iterate through a code block using for statement in C#](https://learn.microsoft.com/en-us/training/modules/csharp-for/) (Part 3), watch [for Iteration Statement](videos/for-iteration-statement.md), then practise [L01](../exercises/L01-trace-a-loop.md), [L02](../exercises/L02-boundaries.md), [L03](../exercises/L03-count-up-and-down.md)
- **3. [Arrays, text and lists](../themes/arrays.md)**: learn [Organize data with arrays and lists in C#](https://learn.microsoft.com/en-us/training/modules/csharp-arrays-lists/) (Part 2), watch [Understanding Arrays](videos/understanding-arrays.md), then practise [R01](../exercises/R01-sum-an-array.md), [R03](../exercises/R03-count-matches.md), [R07](../exercises/R07-count-the-even-values.md)
- **4. [Methods and errors](../themes/methods.md)**: learn [Write your first C# method](https://learn.microsoft.com/en-us/training/modules/write-first-c-sharp-method/) (Part 5), watch [Defining and Calling Methods](videos/defining-and-calling-methods.md), then practise [N02](../exercises/N02-is-multiple-and-count.md), [N01](../exercises/N01-armstrong-with-methods.md), [E02](../exercises/E02-parse-or-zero.md)

</div>
