# Projects

A project is a small program that is **yours**: no tests, no answer key. It mixes what you practised in the exercises. Do one after the Loops theme, or keep it for the end of the course.

<CardList list="projects" />

<div class="gh-only">

1. [Guessing game](guessing-game.md): The computer picks a number, you guess it. Loops, conditions, safe input.
2. [Expense tracker](expense-tracker.md): Type your expenses, see totals, save them to a file. Lists, methods, files.
3. [Text quiz](text-quiz.md): Ask questions, check answers, give a score. Arrays, text, methods.

</div>

## How to work on a project

1. Read the whole page once. Then do the **milestones in order**: each one is a program that runs.
2. Make a new console app **next to** the course folder, not inside it: `dotnet new console -o GuessingGame`, then `cd GuessingGame` and `dotnet run`. Write your code in its `Program.cs`.
3. Stuck? Open **one** hint, try again, then the next. There is no full solution on purpose: two different programs can both be right.
4. Done? Try a stretch goal, or show your program to someone and explain it.
