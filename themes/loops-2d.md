# Loops: draw in 2D

Draw rows and columns with a loop inside a loop.

## After this theme you can

- draw one row, then a full rectangle
- say what the inner and the outer loop each do

## Exercises

Do them from top to bottom. Tick each one when `./ex check` says DONE.
