# Variables and expressions

Store values, compute with them, turn text into numbers.

## After this theme you can

- store a value in a variable of the right type
- turn text into a number with `int.Parse`
- predict the result of `/` and `%` on whole numbers

## What to learn

- **C#:** `int`, `double`, `string`, `bool`; `+ - * /`; integer division and the remainder `%`; `$"..."`.
