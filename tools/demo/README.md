# Demo recording

`demo.tape` records the terminal demo shown in [Getting started](../../docs/getting-started.md#5-do-one-exercise), from a fresh `git clone` in `/tmp`. The captions are the `#` comments.

```bash
tools/demo/record.sh   # needs vhs, the ttyd terminal server, ffmpeg and the .NET SDK
cp /tmp/demo-out/demo-small.gif docs/assets/demo.gif
```

`edit.py` stands in for the editor: it writes the code that Sam types.
