# Microsoft Learn

Microsoft has free C# lessons for beginners: short **modules** you read and try in the browser, and a **video** series. Use them for the theory; use this course to practise.

## The free path

[Foundational C# with Microsoft (free certification, with freeCodeCamp)](https://www.freecodecamp.org/learn/foundational-c-sharp-with-microsoft/) groups six learning paths. You can follow them without the exam:

1. [Write your first code using C#](https://learn.microsoft.com/en-us/training/paths/get-started-c-sharp-part-1/)
2. [Create and run simple C# console applications](https://learn.microsoft.com/en-us/training/paths/get-started-c-sharp-part-2/)
3. [Add logic to C# console applications](https://learn.microsoft.com/en-us/training/paths/get-started-c-sharp-part-3/)
4. [Work with variable data in C# console applications](https://learn.microsoft.com/en-us/training/paths/get-started-c-sharp-part-4/)
5. [Create methods in C# console applications](https://learn.microsoft.com/en-us/training/paths/get-started-c-sharp-part-5/)
6. [Debug C# console applications](https://learn.microsoft.com/en-us/training/paths/get-started-c-sharp-part-6/)

## Videos

[C# for Beginners (19 videos, Scott Hanselman and David Fowler)](https://learn.microsoft.com/en-us/shows/csharp-for-beginners/): each video is 15 to 30 minutes.

## The docs

[A tour of the C# language](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/): the official overview, with small tutorials.
